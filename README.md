# Containerized Microservices Architecture 🐳

A distributed backend application structured completely under a **microservices pattern**. This repository demonstrates production-level infrastructure skills, focusing on service decoupling, containerization, and cloud deployment readiness.

## 🚀 Key Features
*   **Service Decoupling:** Independent services communicating asynchronously to ensure high availability and fault isolation.
*   **Containerization:** Optimized **Docker** configurations for each independent layer.
*   **Orchestration:** Multi-container deployment managed seamlessly via **Docker Compose**.
*   **NoSQL Persistence:** Implements **MongoDB** databases for highly efficient, non-relational document storage.

## 🛠️ Tech Stack
*   **Runtime Environment:** Node.js (Express)
*   **Infrastructure & DevOps:** Docker, Docker Compose, Linux Virtual Machines
*   **Database:** MongoDB / Mongoose
*   **Architecture:** Microservices, Event-Driven Patterns
